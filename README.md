## 실행

Node.js(백업 검증 버전 **v24.13.1**)와 **WebGL 2를 지원하며 하드웨어 가속을 사용할 수 있는 브라우저**가 필요합니다. 외부 npm 패키지에 의존하지 않으므로 `npm install`이나 빌드 과정은 필요하지 않습니다. WebGL 2 환경을 만들 수 없으면 로딩 오류 안내가 표시됩니다.

```powershell
git clone https://github.com/Kexxrix/skywind.git
cd skywind
npm start
```

서버가 준비되면 브라우저에서 [http://127.0.0.1:5173](http://127.0.0.1:5173)을 엽니다. 종료할 때는 서버 터미널에서 `Ctrl+C`를 누릅니다.

`index.html`을 파일 탐색기에서 직접 여는 `file://` 방식은 지원하지 않습니다. ES 모듈과 로컬 오디오 매니페스트를 불러오기 위해 위의 HTTP 서버로 실행해야 합니다.

기본 로컬 서버는 `127.0.0.1`에만 연결을 받습니다. 공개 게임은 위 Sites 주소에서 별도로 실행됩니다. 로컬 포트를 바꾸려면 시작 전에 PowerShell에서 `$env:PORT = '5174'`처럼 지정합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| `W A S D` 또는 방향키 | 기체 이동 |
| `Space` 또는 `J`를 누르고 있기 | 연속 발사 |
| 마우스 왼쪽 버튼을 누른 채 이동 | 포인터 방향으로 이동하며 연속 발사 |
| 터치 화면 왼쪽 가상 조이스틱 | 기체 이동 |
| 터치 화면 오른쪽 `SHOT` 누르기 | 연속 발사 |
| `P` 또는 `Esc` | 일시정지 / 계속하기 |
| `M` 또는 소리 버튼 | 음악·효과음 음소거 전환 / 오디오 활성화 |
| `F` 또는 전체 화면 버튼 | 전체 화면 전환, 브라우저 지원 시 |

타이틀에서 `START`, `Space`, `J`, 또는 터치 `SHOT`으로 시작하면 기체가 왼쪽에서 진입합니다. 게임오버 화면의 `RETRY`로 재도전하거나 `TITLE`로 돌아갈 수 있습니다. 창의 포커스를 잃거나 다른 탭으로 이동하면 진행 중인 게임을 일시정지합니다.

브라우저의 자동재생 정책 때문에 첫 사용자 입력 전에는 음악이 재생되지 않습니다. 타이틀 음악은 소리 버튼으로 활성화할 수 있고, 시작 입력은 게임 음악과 효과음을 활성화합니다.

## 게임 규칙

- 시작 HP와 최대 HP는 **100**입니다. HUD의 `ENERGY` 바와 숫자는 이 프로토타입의 HP를 표시합니다.
- HP가 **0**이 되면 비행 화면이 멈추고 `GAME OVER`, 이번 점수, 최고 점수를 표시합니다.
- 회복 아이템은 HP를 **30** 회복하며 최대 HP를 넘지 않습니다.
- 기본 사격은 빠른 2줄 사격입니다. 무기 강화 아이템은 **14초** 동안 **SPREAD**(5방향), **LANCE**(집중 관통 3줄), **HELIX**(진동하는 4줄) 순서로 패턴을 바꿉니다. 다시 획득하면 다음 패턴으로 바뀌고 14초로 갱신됩니다. 만료 시 기본 사격으로 돌아갑니다.
- 드론 아이템은 **15초** 동안 기체 위아래의 보조 드론 사격을 활성화합니다. 드론은 샷 입력 중 함께 발사합니다.
- HP·점수 아래의 무기 HUD는 기본 무기를 포함해 아이콘·이름·남은 시간·게이지를 항상 표시합니다. 기본 무기는 무제한이며, 드론이 함께 활성화되면 별도 슬롯에 남은 시간을 표시합니다. 무기와 드론은 각자의 실제 타이머로 3초 경고와 만료를 처리합니다.
- 적 격파로 점수를 얻고 연속 격파 시 체인 배수가 올라갑니다. 아이템 획득은 50점입니다.
- 스테이지 숫자는 **18초마다**, 그리고 보스 격파마다 올라갑니다. 전투 난이도는 별도 단계로 관리하며 동시 공격원은 **0~60초 1개, 60~180초 2개, 180~300초 3개, 이후 4개, 420초부터 최대 5개**입니다. 기본 편대 간격은 2.5초에서 60초에 2.3초, 300초에 1.8초로 완만하게 줄어듭니다. 60초 이후에는 **24초 전투·6초 완화**가 반복되고, 완화 중 새 스폰과 공격 예고를 쉬면서 기존 탄과 예고는 유지합니다.
- 몸통 수는 초기 6기에서 최대 14기, 패턴당 탄수는 최대 16발, 활성 적탄은 최대 135발, 적탄 속도는 최대 330px/s로 제한합니다. 초반에는 더 낮은 단계별 상한이 적용되며 일반 적 HP 보너스는 최대 2입니다. 배경 스크롤 속도의 기존 1.3→2.6 증가는 유지합니다.
- 일반 적은 편대 비행, 조준 후 돌진, 제동 후 부채꼴 사격, 고속 군집, 긴 몸체의 곡선 비행, 탄막, 지그재그, 방사형 사격, 저격을 구분하는 **9종**입니다. 공격 전 예고와 조준 고정, 탄속 상한을 적용합니다.
- 첫 보스는 게임 시간 **120초**부터 등장하도록 예약하며 몸통 상한과 완화 구간을 지킵니다. 이후에는 이전 보스를 격파한 뒤 **28~36초** 후에 **WARDEN → IRON CARRIER → LEVIATHAN → QUEEN HIVE** 순서로 예약합니다. 체력이 절반 이하가 되면 공격 단계가 바뀌며, 20초 이상 남은 보스에는 제한된 호위 적이 합류합니다. 보스 경로와 carrier의 세 통로는 현재 화면을 기준으로 표시합니다. 보스 격파 시 적 탄이 정리되고 회복·무기 강화 아이템이 나옵니다.
- 기체는 화면 왼쪽 약 1/3 안에서 움직입니다. 기울기를 반영한 비행 기준 Y=360에서 양쪽 이동 거리를 각각 1.5배로 늘려 **−108~828, 총 936px**를 사용하고, 카메라가 최대 **±156px** 따라가며 기체는 화면 Y=48~672에 머뭅니다. 키보드와 포인터의 기존 좌우 최대 속도 **225px/s**, 상하 최대 속도 **490px/s**는 유지합니다.
- 화면 위쪽 끝으로 이동하면 최고 고도, 아래쪽 끝으로 이동하면 최저 고도로 전환합니다. 카메라 기울기를 반영한 화면 위치를 사용하며, 자동 경로 변화는 중앙에서만 작게 더해져 양끝 고도를 제한하지 않습니다. 고도는 부드럽게 따라가고, 타이틀에서 시작할 때 현재 배경 고도를 이어받습니다.
- 정해진 최종 스테이지나 클리어 종료 없이 HP가 남아 있는 동안 계속 진행합니다.

최고 점수는 현재 브라우저의 `localStorage`에 `skywind.best.v1` 키로 저장합니다. 음소거 설정은 `skywind.muted.v1`에 저장합니다. 같은 브라우저와 같은 접속 주소에서 유지되며, 다른 기기·브라우저 간 동기화는 없습니다. 저장소 사용이 제한되어도 게임은 실행되지만 기록의 영구 보존은 보장되지 않습니다.

## 화면 구현과 참고 영상

현재 배경은 **WebGL 2로 직접 렌더링하는 실시간 3D 환경**입니다. `src/renderer.js`가 `VolumeEnvironment`를 불러오고, `src/volume-environment.js`와 `src/terrain3d.js`가 원근 카메라·지형·숲·구름을 그립니다. 기체·적·탄과 화면 효과는 Canvas 2D에서 합성합니다. 추가 3D 엔진 패키지는 사용하지 않습니다.

숲은 거리별 형태·밀도를 달리한 활엽수와 야자수 **8,572개 인스턴스**로 구성합니다. 나무 기하에 `leaf-surface-v3.png`의 잎 표면을 사용하고, 카메라 이동에 따른 원근 변화와 가림 관계로 깊이와 속도 차이를 표현합니다. 숲 렌더에는 기기 지원 한도 내에서 최대 **4× MSAA**를 적용합니다. 프레임률은 GPU·브라우저·화면 크기에 따라 달라집니다.

구름은 3차원 밀도장을 광선을 따라 샘플링하는 **레이마칭**으로 그립니다. 태양광에 따른 내부 음영과 전투 광원의 위치·거리 감쇠를 구름 부피 안에 반영합니다. 기체 앞뒤를 나눠 합성하므로 구름 사이를 지나갈 때 기체가 가려지고 광원이 구름 속에 번집니다. 청록 추진 궤적, 광원 번짐, 파편과 폭발도 실행 중 렌더링합니다.

패치 1 구름은 위치가 고정된 큰 타원체 덩어리를 먼저 만들고, 옆면·윗면의 작은 돌출부와 표면 노이즈를 붙입니다. 무리별 폭·높이·회전·틈을 다르게 하며, 중앙 전경 광학 배수는 0.80 / 0.65 / 0.50을 비교할 수 있습니다. 기본값은 0.65입니다. 가로 구름 영역을 1,024로 넓히고 비행 경로가 영역을 비스듬히 통과하게 해 같은 윤곽이 짧은 간격으로 반복되는 느낌을 줄였습니다. 밀도·태양광 캐시는 512×64×512이며, 표면의 줄무늬를 줄이기 위해 광선 샘플 간격도 좁혔습니다.

카메라의 장면 고도는 **28~218**, 구름 밀도를 샘플링하는 높이 범위는 **48~238**입니다(이전 58~116). 넓어진 값은 구름 캐시의 표현 범위이며, 실제 가림은 구름 부피·시선·근경 가중치에 따라 결정됩니다. 기체와 카메라 이동 범위는 바꾸지 않았습니다. 최저 고도에서는 숲에 가까운 비행, 최고 고도에서는 구름 위 비행을 보여주도록 구성합니다. 타이틀의 초기 고도는 구름 위에서 시작합니다.

현재 이미지 로더는 `player.png`, `enemies.png`, `enemies-v2.png`, `bosses-v2.png`, `leaf-surface-v3.png`만 불러옵니다. V2의 `src/environment.js`, 구름·수관·수풀 이미지와 Blender 야자수 21그루의 제작 스크립트·원본·렌더는 보존되어 있으며 현재 런타임에서는 사용하지 않습니다. ## 음악과 효과음

사용자가 지정한 Gemini 음악 생성 도구에서 **Lyria로 V2용 음악 6곡**을 새로 생성했습니다. 전투곡은 빠른 왜곡 기타 리프·더블 킥·전자 베이스를 중심으로 한 미래형 산업 메탈 방향이며, 타이틀과 엔딩도 같은 기타·전자 음색 계열로 맞췄습니다. 기존 곡을 복제하지 않는 오리지널 음악을 요청했습니다. 생성 결과의 실제 길이를 유지하고 MP4의 AAC 오디오를 재인코딩 없이 M4A로 추출했습니다. 생성 원본과 이전 음악 6곡은 보존하며, 이전 연결은 `assets/audio/manifest-v1.json`에 남아 있습니다.

| 상태 | 실제 생성 곡명 | 재생 파일 | 길이 |
| --- | --- | --- | ---: |
| 타이틀 | Armored Protocol | `assets/audio/title-v2.m4a` | 138.762초 |
| 일반 비행 | Kinetic Protocol | `assets/audio/normal-v2.m4a` | 133.355초 |

| 무기 강화 또는 드론 활성 | Apex Surge | `assets/audio/powerup-v2.m4a` | 132.232초 |
| 게임오버 | Sunset over the Hull | `assets/audio/ending-v2.m4a` | 132.728초 |

플레이 중 음악 우선순위는 **위급 상태 → 보스전 → 강화 상태 → 일반 비행**입니다. 상태가 바뀌면 약 1.2초 동안 음악을 교차 전환합니다. 게임오버 음악은 한 번 재생하고 다른 상태는 반복합니다. 원곡 길이를 유지했으므로 반복 지점이 완전히 이어지는 무봉합 루프로 편집된 것은 아닙니다.

기존 V3 효과음은 **공개 CC0 샘플로 제작한 WAV 20개**이며 계속 보존합니다. 로컬 패치 1은 제공 후보에서 편집한 단발 WAV 30개를 추가해 무기 발사·명중·피격·교체·만료에 사용하고, 폭발·적 발사 등은 기존 V3를 유지합니다. 새 후보는 **공개 사용 권한 미확인, 직접 청음 미검증**입니다. 원본 67개와 편집본은 `assets/audio/sfx-patch1/source/`, `edited/`에 분리하고 구간·해시·편집 조건은 `provenance.json`에 기록합니다. 총 50개 샘플을 준비하며 발사 이벤트마다 하나의 단발 샘플을 재생합니다. 오프라인 연사 데모는 게임에서 반복 재생하지 않습니다.

V3 제작 당시에는 다음 방식을 사용했습니다. Kenney의 Sci-fi Sounds·Impact Sounds와 Free Firearm Sound Library의 실제 녹음을 사용했습니다. 기본·SPREAD·LANCE·HELIX 발사에 서로 다른 음색과 변주를 적용하고, 폭발은 빠른 충격·저역 몸통·시간차 파편으로 구성합니다. 주요 전투음의 합성 발진기·노이즈는 샘플로 교체했으며 짧은 획득·알림 음표만 합성으로 유지합니다. 동시 샘플 보이스 제한, 컴프레서와 출력 제한으로 겹치는 소리를 제어합니다. 원본과 라이선스는 `assets/audio/sfx-v3/source/`에 보존합니다. V2 BGM 6곡은 그대로 사용합니다.

## 검증 명령

```powershell
npm test
npm run check
```

PATCH2의 전체 `npm test`는 **78개 모두 통과**한 기록이 있습니다. 중앙 핵·고속 상대 이동·프레임/카메라 판정과 오디오 종료 경계 회귀가 추가되었습니다. 최초 백업 검증은 [백업 검증 기록](docs/BACKUP_VERIFICATION.md)을 참고하세요. HP·점수·재시작, 동일 시드 재현, 확장 이동과 카메라 역변환, 5분 난이도 상한·완화, 아홉 적 행동, 네 보스의 패턴·양끝 30초 가시성, carrier 통로, 투사체·아이템 제거, 무기·드론 독립 타이머와 원래 탄종 보존, 오디오 캐시·발음 제한·일시정지 회귀를 확인합니다. `npm run check`는 `src/volume-environment.js`·`src/terrain3d.js` 등 현재 실행 모듈과 보존된 `src/environment.js`의 JavaScript 문법을 검사합니다.

위 명령은 실제 화면, 오디오 출력, 터치 기기의 입력을 대신 검증하지 않습니다. 시각·조작·오디오 통합 검증은 실행 중인 게임을 브라우저로 열어 별도로 수행합니다.
