# SkyWind

숲 위 저공비행과 구름층 사이의 상승·하강을 배경으로 하는 웹 횡스크롤 슈팅 게임입니다. WebGL 2의 실시간 3D 숲·구름 배경과 Canvas 2D의 기체·적·탄·전투 효과를 합성합니다.

## 현재 작업 단계

**기본 기능 구현 후 전체 개선을 설계했고, 현재는 전투 감각을 먼저 확인할 1차 구현 범위를 정리했습니다. 1차 게임 구현은 아직 시작하지 않았습니다.**

다른 환경에서 이어서 작업하려면 [첫 구현 시작 안내](FIRST_IMPLEMENTATION_HANDOFF.md)를 먼저 확인하세요. 새 작업에 전달할 지시문, 환경 준비, 문서 읽기 순서, 저장소에 포함된 HUD 참고 이미지와 검증 기준이 있습니다.

현재 실행본에는 무한 진행, 일반 적 9종과 보스 4종, 강화 무기와 드론·회복, SV-01 기체 동작, 파일럿 HUD FX3, 상태별 음악·효과음, 최고 점수 저장이 들어 있습니다. 최신 구현과 확인 범위는 [HANDOFF.md](HANDOFF.md)를 기준으로 확인합니다.

## 로컬 실행

Node.js와 WebGL 2 및 하드웨어 가속을 지원하는 브라우저가 필요합니다. 현재 실행용 npm 의존성이 없어 `npm install`은 필요하지 않습니다.

```sh
git clone https://github.com/Kexxrix/skywind.git
cd skywind
npm start
```

이미 저장소가 있으면 그 폴더에서 `npm start`만 실행합니다. 기본 주소는 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)이며 종료는 해당 터미널에서 Ctrl+C입니다. 포트 변경은 PowerShell에서 `$env:PORT = '5174'`처럼 지정합니다.

`index.html`을 직접 여는 `file://` 방식은 지원하지 않습니다. 게임은 HTTP 서버로 실행해야 합니다. WebGL 2 환경을 만들 수 없거나 필수 자산을 읽지 못하면 로딩 오류 안내가 표시됩니다.

## 현재 조작

| 입력 | 동작 |
|---|---|
| WASD 또는 방향키 | 기체 이동 |
| Space 또는 J를 누르고 있기 | 연속 발사 |
| 마우스 왼쪽 버튼을 누른 채 이동 | 포인터 방향으로 이동하며 발사 |
| 터치 화면 왼쪽 조이스틱 / 오른쪽 SHOT | 이동 / 발사 |
| P 또는 Esc | 일시정지·계속하기 |
| M 또는 소리 버튼 | 음악·효과음 음소거 전환·오디오 활성화 |
| F 또는 전체 화면 버튼 | 브라우저가 지원하면 전체 화면 전환 |

START 또는 시작 입력으로 게임을 시작하고, 게임오버의 RETRY로 재도전하거나 TITLE로 돌아갑니다. 진행 중 창의 포커스를 잃거나 다른 탭으로 이동하면 자동으로 일시정지합니다.

첫 사용자 입력 전에는 브라우저 정책 때문에 음악이 재생되지 않을 수 있습니다. 최고 점수와 음소거 설정은 각 브라우저·접속 주소의 localStorage에 저장되며 기기 간 자동 동기화는 없습니다.

## 검증 명령

```sh
npm test
npm run check
npm run build:site
```

변경에 맞는 실행 시점과 실제 화면·조작 검증은 [검증 기준](docs/plan/QUALITY.md)을 따릅니다. `build:site`는 실행에 필요한 파일만 `dist/`에 생성하며 제공 사운드의 승인 기록과 편집본 해시를 확인합니다. 정적 빌드 생성과 실제 공개 배포는 별도입니다.

## 공개 게임과 자료

[SkyWind 공개 게임](https://skywind.kexxadrix.chatgpt.site/)은 기존 Sites 주소입니다. 최근 게시 근거는 [2026-09-08 공개 버전 5 기록](docs/PUBLIC_UPDATE_PILOT_20260908.md)입니다. GitHub push가 Sites 자동 배포를 뜻하지 않으며, 이후 배포는 해당 사용자 승인 범위에서 수행합니다.

- [사운드 공개 사용 확인](docs/RIGHTS_STATUS.md)과 각 자산의 provenance를 보존합니다. 기존 승인 범위를 새로운 자산에 임의 적용하지 않습니다.
- [참고 영상 분석](docs/REFERENCE_ANALYSIS.md), [V3 화면·움직임 분석](docs/REFERENCE_V3.md), [아트 출처](docs/ART_SOURCES.md), [음악 제작 기록](docs/AUDIO_V2.md), [효과음 기록](docs/SFX_V3.md)은 제작 근거입니다.
- [PATCH2 상태와 당시 검증](docs/patch2/STATUS.md), [기체 시퀀스 적용 기록](docs/SV01_R4_CHANGED_FILES.md), [파일럿 효과 기록](docs/pilot-ui/FX_REVISION.md)은 기능별 이력입니다.
- 제작 원본과 실행 자산은 `assets/`에 구분하여 보관합니다. 현재 사용하지 않는 이전 자산도 보존되어 있으므로 파일 존재만으로 현재 로딩된다고 판단하지 않습니다.
- 원래 참고 영상 `SampleGame.mp4`, 기기별 임시 폴더와 대용량 원시 QA 녹화는 공개 저장소에 없습니다. 제작 음악의 원본 MP4와 Blender·PNG 원본은 이와 구분되는 보존 자료입니다.
