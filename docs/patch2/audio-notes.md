# PATCH2 사운드 종료 상태 검토

검토 자료: `SkyWind_Patch1_Review_20260906/REVIEW.md` 6절. 변경 범위는 `src/audio.js`, `tests/audio.test.js`입니다. 음원 파일·다운로드 경로·음악 목록·0.28 음악 볼륨·1,200ms 크로스페이드·무기 규칙·발사 간격은 유지했습니다.

## 재현한 문제와 수정

- **일시정지:** 기존 코드는 AudioContext만 정지해 재생 중인 꼬리와 미래 시각의 UI 음표를 보존했습니다. 재개 시 이전 소리가 이어질 수 있었습니다. 정지 전에 활성/퇴장 중인 샘플과 예약된 UI 음표를 정지·연결 해제하고, 효과음 제한 시각과 발사 버스 감쇠를 초기화했습니다. 재개 후에는 새 실제 이벤트만 소리를 냅니다.
- **음소거:** gain만 내리던 처리를 보완해 이전 소리를 폐기합니다. 빠르게 음소거를 풀어도 이전 피격·획득음 꼬리가 되살아나지 않습니다. 음악 재생 위치와 디코드된 버퍼는 보존합니다.
- **게임오버:** 기존 전투·알림 잔류음을 정리하되, 바로 발생한 고정 플레이어 피격음과 플레이어 파괴음은 남깁니다. 기존 엔딩 음표는 한 번만 예약하고 이후 늦은 만료·발사·중복 게임오버 이벤트를 무시합니다.
- **재시작·타이틀:** 공개 메서드 `audio.resetEffects()`가 남은 엔딩 음표까지 정리하고 새 플레이의 소리 입력을 엽니다. root가 `main.js`의 `start()`와 `toTitle()` 경계에 연결합니다. 게임의 `start` 이벤트도 같은 초기화를 수행합니다.
- **빠른 정지/재개:** 비동기 `suspend()`·`resume()` 완료가 뒤늦게 도착해 최신 정지 상태를 뒤집는 경합을 수정했습니다. 정지 후 늦게 완료된 음악 `play()`도 다시 정지합니다. 음악 선택 및 크로스페이드 구성은 바꾸지 않았습니다.

종료 경계에서 효과음 노드를 바로 정지·연결 해제하는 정책입니다. 음악은 기존 두 데크와 크로스페이드를 유지하며, 새 사운드·타이머·루프·의존성은 추가하지 않았습니다.

## 고정 피격음과 우선순위

현재 플레이어 피격은 `player-damage-fixed` 한 파일, **source gain 0.9 / playbackRate 1 / pan 0 / 최대 300ms / priority 6**입니다. 새 테스트는 기록용 `voice.volume`뿐 아니라 실제 모의 GainNode의 `gain.value`도 확인합니다. 일반 명중보다 우선하며 게임오버에서도 실제 플레이어 피격·파괴 큐를 즉시 지우지 않습니다.

교체·만료는 priority 5, 파괴는 4, 일반 명중은 3입니다. 기존 동시 활성 20개·퇴장 중 4개 상한과 보호 큐 테스트가 통과했습니다. Impact 버스 0.94와 전체 SFX 0.7, 공용 compressor/saturator는 유지하므로 고정 source gain을 최종 혼합의 동일 청감 음량으로 해석하지 않습니다.

## 검증 및 남은 항목

새 종료 상태 테스트 5개는 수정 전 모두 실패했고 수정 후 통과했습니다. 기존 항목을 포함한 **오디오 테스트 17/17**, `node --check src/audio.js`가 통과했습니다. Canvas·게임 규칙과 무관한 Web Audio 수명 관리만 수정했습니다.

추가 전체 테스트 실행 시점에는 64개 중 63개가 통과했고, 별도 게임 항목인 `tests/game.test.js`의 worm 몸체 끝 접촉 판정 1개가 실패해 root에 전달했습니다. 해당 게임 파일은 이 하위 작업에서 수정하지 않았으며, 전체 통과로 기록하지 않습니다.

이 결과는 모의 Web Audio 노드의 실행 검증입니다. root의 실제 브라우저 QA에서 정지·재개·게임오버·빠른 재시작의 소스 수와 gain 관측, 실제 혼합 녹화를 확인해야 합니다. 직접 청음·타격감·피로도·마지막 합성 음질의 승인은 **미검증**입니다. 공개 사용 권한 확인이나 배포는 이 하위 작업에서 수행하지 않았습니다.
