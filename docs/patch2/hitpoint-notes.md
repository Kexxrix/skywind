# SkyWind PATCH2 — 중앙 피격점 구현·검증

## 결과와 변경 범위

플레이어 피해 반경을 기존 17에서 **명확한 중앙 핵 반경 1.85**로 줄였다. 단위는 1280×720 논리 게임 좌표이며 실제 화면 크기에 따라 함께 확대·축소된다. 기존 표시의 arc 반경은 2.6이었으나, 같은 경로에 두께 1.5의 stroke가 겹쳐 밝은 핵의 실제 반경은 2.6−0.75=1.85였다. 공유 export `PLAYER_HIT_RADIUS`가 이 값을 제공한다. 표시를 그리는 renderer는 부모 작업 소유이며 이 작업에서는 수정하지 않았다.

날개·기체 이미지·후광·플레어·장식 링 크기는 피해 판정에 참여하지 않는다. 적탄의 실제 원형 몸체가 작은 플레이어 원에 겹칠 때 피해가 발생한다. 예를 들어 반경 5.5 적탄은 중심 간 거리 7.35 미만이 충돌 범위이며, 기존 22.5보다 좁다. 단순 플레이어 원 면적 비율은 약 1.18%가 되지만 이를 사람의 피격률이나 난이도 감소 비율로 해석하면 안 된다.

수정 파일:

- `src/game.js`: 공유 핵 반경, 아이템 획득 여유의 분리, 적탄/적 본체의 상대 이동 선분 판정.
- `tests/player-hitpoint.test.js`: 새 14개 테스트. 여러 타입·각도·프레임률·경계 및 실제 Renderer와 피해 반경의 일치를 검증한다.
- `tests/game.test.js`: worm 끝 접촉 테스트의 플레이어 배치만 회전된 실제 몸체 축 위로 수정. 기존 적 형태·플레이어 탄 검증은 유지했다.
- `.work/patch2-20260906/hitpoint-impact.mjs` 및 `hitpoint-impact.json`: 일반 게임 규칙의 동일 시드/고정 입력 전후 비교 도구와 결과. 게임 런타임에 포함하지 않는다.

## 실제 피해 경로 감사

`src/game.js`에서 HP 감소는 `damagePlayer` 한 곳이며 호출 경로는 아래 두 종류다. HP 회복은 별도 아이템 충돌 경로다.

| 피해 원인 | 유지한 대상 형상·수치 | 변경한 플레이어 부분 |
|---|---|---|
| orb·plasma·needle 적탄 | 기존 bullet.radius의 원. 일반 5.5, 보스 기본 7 및 기존 개별 옵션을 유지 | 끝점 간 거리 검사에서 상대 이동 선분과 작은 핵의 겹침으로 변경 |
| mine | 기존 원 반경 12, 피해 19, arming 0.8초 유지 | arming 종료 전의 이동 구간은 판정에서 제외. 프레임 도중 활성화되면 활성화 이후 부분만 검사 |
| 일반 원형 적 | 기존 enemy.radius×0.7, 접촉 피해 22 유지 | 플레이어 반경만 1.85. 적과 플레이어의 양쪽 이동을 반영 |
| worm | 기존 회전 타원, 중심 오프셋 (5,−7), 축 반경 69/19 유지 | 타원 확장에 더하는 플레이어 반경만 1.85 |
| needle 본체 | 기존 회전 타원, 중심 오프셋 (0,0), 축 반경 50/22 유지 | 위와 동일 |
| 네 보스 본체 | 기존 원 반경 92/95/78/90의 0.7배, 접촉 피해 30 유지 | 플레이어 반경만 1.85 및 상대 이동 판정 |

현재 소스에는 별도 지속 레이저/선분 레이저 피해 경로가 없다. needle이라는 시각 종류도 기존 원형 projectile 판정이다. 존재하지 않는 레이저를 새로 추가하거나 다른 충돌 형태로 바꾸지 않았다.

피해량, HP, 0.85초 무적, 시작 무적, 적/탄 속도·공격 패턴·난이도 일정, 무기 수명·탄 수·위력, 드롭 규칙은 바꾸지 않았다. 새 판정은 난수를 사용하지 않는다. 발사체의 기존 처리 순서와 적 처치/게임오버의 순서도 유지한다.

## 연속 이동·경계 처리

매 최대 1/120초 내부 스텝에서 플레이어·적의 시작 좌표, 적탄 시작 좌표를 보존한다. 상대 좌표에서 시작점부터 끝점까지의 선분이 충돌 범위 안에 들어오는지 검사한다. 따라서 양쪽 끝점이 핵 밖이어도 중간에 통과하면 피해가 발생하며, 같은 방향으로 떨어져 움직이는 두 궤적을 단순히 공간상 교차했다고 오인하지 않는다. 적 생성 중 추가되는 호위기도 해당 업데이트에서 시작 pose가 저장된다.

기존의 엄격한 내부 겹침 정책을 유지하여 수학적 접선은 무피해다. 거리 비교의 작은 수치 여유(제곱 거리 기준 1e−10)는 부동소수점 오차로 접선이 내부처럼 보이는 경우를 막는다. 지뢰 arming과 플레이어 무적이 스텝 중 끝나면 피해가 가능한 이후 구간만 검사한다. 무적이 끝나기 전에 지나간 탄을 나중에 소급해 피격 처리하지 않는다.

충돌 계산에 카메라 변환이나 화면 좌표를 넣지 않는다. 실제 월드 좌표의 이동만 사용한다. 30/60/144Hz 입력 업데이트와 상·중·하 고도/카메라 위치에서 같은 월드 충돌·스침 결과를 테스트했다.

### 형상 처리의 정확한 한계

- 원형 대상끼리는 각 내부 스텝에서 선형 상대 이동에 대한 연속 판정이다. 실제 가속 곡선 전체를 해석적으로 적분하는 물리 엔진은 아니다. 기존 최대 1/120초 스텝을 유지한다.
- 타원 적은 기존 방식대로 두 축 반경에 플레이어 원 반경을 더한 확장 타원이다. 이것은 타원과 원의 정확한 Minkowski 합이나 이미지 알파의 픽셀 단위 판정이 아니다. 적의 기존 몸체 판정 관례를 유지했다.
- 회전 타원은 시작/끝 pose의 로컬 좌표 사이를 검사한다. 작은 스텝 사이의 기존 회전은 반영하지만 임의의 큰 회전 도중 연속적인 모든 각도를 정확하게 풀지는 않는다. 실제 접촉 구간의 worm/needle 동작과 정적인 여러 회전 각도를 검증했으며, 미래에 빠른 회전 공격을 추가한다면 별도 회전 스윕 검증이 필요하다.

## 아이템 획득 범위 유지

아이템의 획득 기준을 피해 반경에서 분리했다. 기존 여유 `17 + 14 = 31`을 `PLAYER_PICKUP_REACH`로 유지하므로 일반 반경 22 아이템은 중심 간 거리 53 미만에서 수집된다. health/power/drone 세 종류 모두 52.9에서 수집, 53.1에서 미수집을 확인했다. 새로운 자석·흡입·자동 수집 동작은 없다.

### 회전·카메라 재검토

구현 후 다시 읽은 범위에서 추가 수정이 필요한 실제 경로 오류를 발견하지 못했다. 카메라/뱅킹은 피해 함수에 입력되지 않고, 스텝 전후의 실제 월드 위치가 상대 선분에 들어간다. 기체 자체는 원형 핵이므로 자세 회전에 영향을 받지 않는다.

worm의 기존 회전식은 진폭 0.18, 각 주파수 1.9로 한 최대 내부 스텝의 각도 변화가 약 0.00285rad 이하다. 잠기지 않은 needle은 약 0.000333rad 이하이며, 잠금 자세는 고정된다. needle이 잠금을 풀어 큰 자세 차이가 생길 수 있는 x=470 부근은 플레이어 최대 월드 x=380과 90가량 떨어져 있어 기존 50+1.85 타원의 근접 접촉 영역 밖이다. 이 실제 동작 범위가 작은 스텝의 로컬 좌표 선분 근사를 지지한다. 임의의 큰 회전·순간이동에 대한 정확한 연속 회전 판정이라는 주장은 하지 않는다.

옛 worm 테스트는 회전된 몸체를 고려하지 않은 세계좌표 위치를 사용했다. 이 지점은 작은 핵 기준으로 실제 타원 밖이고 큰 17 반경의 가장자리로만 닿던 위치였다. 이를 통과시키려고 타원을 키우지 않고, 테스트 목적대로 실제 회전 몸체 끝 안에 핵이 놓이도록 배치만 고쳤다.

## 난이도 영향: 동일 시드·입력 전후 비교

20개 시드, 60Hz, 최대 120초의 동일 비반응형 키보드 패턴으로 기준본과 변경본을 실행했다. 실제 시작 진입을 포함하고 HP·무적·적·드롭·시간을 주입하거나 보정하지 않았다. 각 코호트 20회 실행을 다시 수행해 결과의 완전 일치를 확인했다. 원본 코드 해시, 20행 결과와 사분위수는 `hitpoint-impact.json`에 있다.

| 지표 | 기준본 반경 17 | 변경본 핵 1.85 + 스윕 |
|---|---:|---:|
| 120초 생존 | 4/20 | 18/20 |
| 생존시간 최소/중앙/평균 | 70.742 / 99.288 / 97.334초 | 96.950 / 120.000 / 118.343초 |
| 최종 HP 최소/중앙/평균/최대 | 0 / 0 / 3.9 / 30 | 0 / 42 / 38.2 / 74 |
| 실제 피해 사건 최소/중앙/평균/최대 | 5 / 6 / 6.25 / 9 | 2 / 4 / 3.95 / 6 |
| 누적 실제 HP 손실 최소/중앙/평균/최대 | 70 / 100 / 100.6 / 130 | 34 / 68 / 66.3 / 100 |

회복을 받을 수 있으므로 누적 HP 손실은 100을 넘을 수 있다. 과잉 피해는 남은 HP로 제한해 합산하고 같은 프레임 회복까지 순서대로 검산했다.

**이 입력 패턴에서는 생존이 뚜렷하게 쉬워졌다.** 적 수·탄 속도·공격력 등을 올리는 보상 밸런스 변경은 하지 않았다. 이 결과는 작은 핵과 연속 판정 변경을 합친 실제 영향이며, 두 요소의 개별 기여를 분리한 실험은 아니다.

한 가지 고정 패턴과 20개 시드는 사람의 회피 능력·가독성·적정 난이도 만족을 측정하지 않는다. 120초를 넘는 보스전/후반 난이도도 측정하지 않았다. 같은 시작 시드/입력이라도 HP 차이가 드롭의 조건부 난수 분기를 바꾸고 이후 상황이 달라질 수 있으므로 모든 적 배치가 끝까지 동일한 통제 재생이라고 주장하지 않는다. 실제 화면에서 표시된 핵과 스침이 직관적으로 맞는지는 부모 작업의 브라우저 QA로 별도 확인해야 한다.
