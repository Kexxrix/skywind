## 2. 프로젝트 목적과 구조

SkyWind는 숲·구름 위의 상승·하강 비행을 배경으로 한 **브라우저 횡스크롤 슈팅 게임**이다. 키보드·마우스와 터치 입력을 제공한다. 대상 사용자는 웹에서 바로 슈팅 게임을 즐기는 이용자로 판단되며, 연령·시장·수익화 대상은 명시되어 있지 않다. 모바일·노트북·패드에서 이전 버전의 기본 플레이가 원활했다는 사용자 피드백은 존재한다. 기기 모델·FPS·시간이 없어 이를 현재 모든 기기의 성능 보증으로 확대하지 않는다(`README.md:3`, `HANDOFF.md:76`).
