## 이전 조정 (FX2)

로컬 구현. 이전 초상 UI의 상태 연결은 정상이나, 중앙 오버레이 알파가 중첩되어 저체력 때 약 0.7~2.4%, 피격 최고 약 4.2%만 더해지고 진동도 작고 짧았다. 이번에는 실제 화면에서 읽히도록 표현을 강화했다.

## 변경

- **붉은 면색과 빛 분리:** `.pilot-tint`는 얼굴의 색조, `.pilot-fx`는 발광선·스캔·가장자리 빛, `.pilot-impact`는 최초 충격광을 담당한다. 모두 고정 마스크 내부에만 표시한다.
- **피격:** 0.42→0.64초. 즉시 강한 붉은 섬광, 0.30초 부근 약한 두 번째 점멸 후 안정된다. 충격광은 0.16초 감쇠한다. 내부 이미지 진동은 0.22→0.36초, 최대 3×2→7×4px. 첫 반동을 낮은 주파수로 명확하게 만들고 작은 잔진동으로 끝낸다. 이미지 여백은 4→9px로 늘렸다.
- **저체력:** HP 25% 이하에서 지속적인 붉은 색층과 경고 선·바이저 스캔·작은 경고 기호. 주기는 25%에서 1.8초, 10%에서 1.2초, 0%에서 0.8초. HP가 바뀌어도 현재 맥동의 밝기가 튀지 않게 위상을 누적한다.
- **파워업:** 청색 색층과 가장자리 발광·스캔·얇은 HUD 라인, 1.8초의 부드러운 맥동. 얼굴은 계속 읽을 수 있게 유지한다.
- **실제 시간:** 게임의 제한된 dt를 HUD에 공유하지 않고, 초상 효과만 실제 RAF 경과시간을 사용한다. 시작·재시작·타이틀·재개 시 기준시각을 초기화하고 일시정지 시간을 제외한다. 게임 시뮬레이션 dt와 모든 밸런스는 유지한다.

상수는 `src/pilot-state.js`에 있다. FX opacity 범위는 파워업 .30~.58 / 저체력 .38~.86 / 피격 .32~.95, 독립 색층 opacity는 .06~.14 / .16~.38 / .16~.56이다. OS 동작 축소 설정에서는 진동·이동 스캔 없이 읽히는 고정 색조를 사용한다.

## 실제 검증

- 인앱 브라우저에서 통제된 **실제 게임**의 탄 충돌로 HP25→12를 만들었다. 1.7초·103프레임에서 피격 시작 `(7,2.57687)`px, 50ms에 `(-3.6452,-2.05017)`px의 반동, 약650ms에 저체력 복귀를 관측했다.
- 저체력 2.8초·169프레임에서 색층 opacity .16~.38의 맥동을 관측했다. 모든 프레임에서 마스크/프레임과 중앙 HP 위치가 동일했다. [프레임 기록](fx2-motion-checks.json)
