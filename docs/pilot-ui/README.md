## 배치와 레이어

사용자가 추가한 1:1 마스크 예시를 기준으로 **1920×1080 게임 영역에서 x=0, y=32, 폭=362, 높이=108px**이다. 오른쪽 아래 꼭짓점은 x=282이며 CSS `clip-path`가 같은 형상을 만든다. 작은 게임 영역에서는 같은 비율로 줄어든다.

`#pilot-hud`는 게임 캔버스와 독립된 고정 DOM HUD다. `.pilot-mask` 안에 이미지와 FX를 넣고, 별도 `.pilot-frame`이 얇은 외곽선을 표시한다. **흔들림은 `.pilot-images`에만 적용**한다. 프레임·마스크·FX에는 transform을 적용하지 않는다. 이미지 레이어를 각 방향 4px 넓혀 최대 3×2px 흔들림에서도 빈 부분이 노출되지 않게 했다.

모든 초상에 같은 `object-fit: cover`, `object-position: 50% 40%`를 사용한다. 제공된 피격 원본의 얼굴 방향·표정 차이는 원본 그대로다. 프레임 배치와 크롭 기준은 `style.css`의 마지막 파일럿 블록에서 조정할 수 있다. 중앙 HP 숫자·게이지·점수·무기 UI는 이동하지 않았다.

## 원본 이미지 배치

`Temp` 원본은 유지했다. 아래 실행용 영문 파일명은 경로 호환성을 위한 **바이트 동일 사본**이며 픽셀 편집·재생성·재압축은 하지 않았다. 샘플 화면과 흰색 마스크 이미지는 게임에 넣지 않았다. 원본/사본 SHA-256은 [assets.json](assets.json)에 있다.

|---|---|

| 기본표정2.png | `assets/art/pilot/blink.png` |

5장을 시작 시 미리 로드·디코드하고 준비가 끝나야 게임을 시작한다. 상태 전환 때는 이미 준비된 이미지의 표시 여부만 바꾼다. 파일 로딩에 실패하면 기존 로딩 오류/재시도 화면으로 안내한다.

## 상태와 조정값

우선순위는 **피격 > 저체력 > 파워업 > 기본**이다. 조정값은 `src/pilot-state.js`의 `PILOT_UI_CONFIG`에 모았다. 시간 단위는 초, 흔들림 단위는 표시 CSS 픽셀이다.

| 상태 | 실제 조건과 동작 | 주요 값 |
|---|---|---|
| 기본 | 기본표정1. 독립 난수로 눈 깜빡일 때만 기본표정2 | 대기 3~6초, 감김 0.11초 |
| 파워업 | `powerTime > 0` 또는 `droneTime > 0`. 파워업 원본 + 약한 청색 라인/스캔/맥동 | 주기 1.8초, FX opacity 0.045~0.14 |
| 저체력 | `hp / maxHp <= 0.25`. 낮은체력 원본 + 적색 경고. HP가 낮아질수록 맥동이 빨라짐 | 25%에서 1.8초, 10%에서 1.14초, 0%에서 0.7초. opacity 0.07~0.24 |
| 피격 | 실제 게임의 `hit`, `player: true`, `damage > 0` 이벤트. 피격 원본 + 짧은 적색 점멸 + 내부 이미지 진동 | 표시 0.42초, 진동 0.22초, 진폭 X=3/Y=2px. 점멸 0.18초 주기, 최대 opacity 0.42에서 감쇠 |

위 opacity는 전체 FX 레이어의 값이며 내부 그라데이션에도 알파가 있어 얼굴 전체를 단색으로 덮지 않는다. 초상 원본에 이미 있는 바이저 HUD는 그대로 사용하고, 추가 라인·광원·경고 기호·스캔만 CSS로 그린다. 새 이펙트 PNG는 없다.

- 피격 종료 시 **그 시점의 실제 HP와 강화 타이머**로 상태를 다시 결정한다.
- 회복으로 25%를 넘으면 강화가 남아 있을 때 파워업, 아니면 기본으로 돌아간다.
- 기본 이외 상태는 blink를 즉시 중단한다. 기본으로 돌아오면 새 3~6초 간격부터 시작한다.
- UI 난수는 게임 RNG를 소비하지 않아 적/아이템 생성 결과를 바꾸지 않는다.
- 일시정지 시 모든 UI 타이머·점멸·진동이 정지한다. 재시작/타이틀 복귀는 타이머를 초기화한다.
- 타이틀과 로딩에서는 숨겨지고, 진입/플레이에서 표시된다. 치명타도 피격 표정을 거친 뒤 게임오버 오버레이 뒤에 남는다.
- OS의 동작 축소 설정에서는 진동과 이동 스캔을 끄고 상태 색을 일정하게 표시한다.

## 변경 코드

- `src/pilot-state.js`: 독립 상태·blink·경고·피격 타이머 및 조정값.
- `src/pilot-ui.js`: 5개 이미지 로딩, 상태와 DOM/FX 연결.
- `src/main.js`: 실제 이벤트/게임 루프 연결, 시작·타이틀 초기화, 초상 로딩 대기.
- `index.html`, `style.css`: 고정 사다리꼴/이미지/FX/프레임 레이어.
- `tools/build-site.mjs`: 모듈 2개와 초상 5장만 정적 빌드에 추가.
- `package.json`: 신규 모듈 구문 검사 추가. 의존성 추가 없음.
- `tests/pilot-state.test.js`, `tests/pilot-ui.test.js`: 상태 경계·DOM 레이어·reset·동작 축소·로딩 실패 회귀.

기존 `src/game.js`의 규칙·피해·무기/드롭·난이도, 배경과 사운드는 이번 작업에서 수정하지 않았다.

## 검증 결과

- `npm test`: **96/96 통과**. 이번 추가 상태 테스트 10개 + DOM 테스트 4개 포함.
- `npm run check`, `npm run build:site`, `git diff --check`: 통과. 빌드 **101개 파일**, 샘플 화면/Temp/QA 제외.
- Chrome 실제 기본 게임 시작/초상 표시 확인. 빈 화면·로딩 정체·콘솔 오류 없음.
- 1920×1080에서 네 상태 모두 마스크/프레임 **(0,32,362,108)**, 중앙 HUD는 **(852,20), 폭216px**로 동일. 피격에서만 이미지 `translate(3px,1.28844px)`이며 마스크/프레임/FX transform은 `none`. [최종 치수 기록](final-layout.json)
- 844×390 가로 뷰포트에서 초상 폭130.72px, 중앙 HUD와 겹치지 않음. [작은 화면 기록](small-layout.json)
- 기본 상태에서 약 3.98초 후 실제 blink 이미지 표시 관측.
- 통제된 게임 장면에서 **실제 강화 아이템 획득 → 파워업**, **HP25% + 강화 → 저체력**, **실제 탄 충돌 HP25→12 → 피격 → 저체력**, **회복 아이템 HP12→42 → 파워업**, **타이머 만료 → 기본**을 확인했다. [전환 기록](browser-checks.json)
