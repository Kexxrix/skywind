## 2. 프로젝트 목적과 구조

SkyWind는 숲 위 저공비행과 구름층 사이 상승·하강을 배경으로 하는 웹 횡스크롤 슈팅 게임이다. 이용자는 키보드·마우스·터치로 이동하고 연속 발사하며, 고도·무기·보급·탄막 통로를 선택한다. 브라우저 이용자가 대상이라는 것은 실제 입력 지원에서 확인된다. 연령층·상용 판매 모델·정량적인 시장 대상은 문서에서 확정되어 있지 않다.

기술은 **HTML/CSS와 JavaScript ES 모듈, Canvas 2D, WebGL 2, Web Audio**다. Node.js 기본 HTTP 서버와 기본 테스트 러너를 사용한다. `package.json`에는 실행용·개발용 npm 의존성 선언이 없고, `node_modules`도 없다. 게임 실행에 `npm install`이 필요하지 않다. 이번 환경은 Windows/PowerShell, Node.js `v24.13.1`, npm `11.8.0`이다. WebGL 2와 하드웨어 가속을 지원하는 브라우저가 필요하며 `file://` 실행은 지원하지 않는다.

이 읽기 전용 조사에서 다른 코드/QA 스레드를 생성하지 않았고, 기존 서버·브라우저·사용자 설정을 변경하지 않았다. 후속 부모 지시의12시간 제작은 이 보고서의22:33 기준 조사와 별도이며 기존 담당자들이별도 작업트리에서 계속한다. 새 설치/업데이트·외부 유료API·실데이터 쓰기·공개 게시/배포는0이다. 원격 조회는 승인된 공개 읽기 전용 검사였다. 보고서의 Library 첨부는 이 새 문서에 한정하며, 과거8시간 보고서·아트의 실패한 이전을 재시도하지 않는다. 첨부 성공 여부/반환ID 또는 정확한 차단 원인은 최종 전달 응답에서 별도 명시한다.
