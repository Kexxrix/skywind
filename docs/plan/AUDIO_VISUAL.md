# SkyWind 빛·소리·전투 연출 방향

문서판: **검토 초안 4 / 2026-09-08 KST / 구현 미승인**.

이 문서는 사용자가 제시한 루미네스 참조 방향을 구체화한다. 빛·소리의 방향은 D26, 음악 직접 연결 제외는 D27, 텐션업의 탄색·발사/적 명중음 고조는 D34로 확정됐다. 메카닉의 공통 디자인은 D29~D31이며 아래 사건별 세부 표현·음원 레시피는 검토 제안이다. 전투 수치는 [레벨 설계](LEVEL_DESIGN.md)와 [탄막·텐션업](BARRAGE_DESIGN.md), 구현 승인 상태는 [결정 기록](DECISIONS.md)을 따른다.

## 1. 사용자가 제시한 목표

- 전체 게임 분위기의 주요 참조는 음악 퍼즐 게임 **루미네스**다.
- 블록이 터질 때 빛과 소리가 어우러지는 즐거움을 슈팅의 발사·명중·격파·탄막에 적용한다.
- 파티클, 플레이어 탄, 적탄, 발사음과 적 명중음이 함께 작동해 눈과 귀가 즐겁고 **구경하는 것만으로도 재미있는 전투**를 지향한다.
- 어떤 방식으로 구현 가능한지 검토하고 기존 문서와 충돌하는 부분을 다듬는다.

특정 루미네스 작품·스킨·곡·영상 구간은 아직 지정되지 않았다. 조사에서는 공식 LUMINES REMASTERED 소개의 빛·소리·행동 반응이라는 공통 원리만 확인했다. 아래 제안이 특정 장면을 직접 보고 재현한 분석이라고 쓰지 않는다.

메카닉 디자인은 [건담 00 오마주와 Blender 제작](MECHA_ART.md), 빛·소리 반응은 이 문서의 루미네스 참조를 따른다. 기존 밝은 낮 → 가속 → 밤 보스 → 낮 복귀와 결합하며 플레이어·파일럿·배경을 추상 퍼즐 화면으로 바꾸지 않는다.

## 2. 슈팅에 적용하는 기본 원칙

**한 번의 전투 행동이 하나의 빛과 소리 반응으로 읽히게 한다.** 발사음·탄의 형태·명중 빛·격파 파편이 무기별로 연결되며, 많은 적을 연속으로 정리할 때 화면과 소리가 함께 풍성해지는 방향이다.

즉각적인 전투 반응과 음악적인 장식을 분리하는 안을 추천한다.

1. 버튼 입력, 발사, 명중, 피해, 격파, 점수는 원래 게임 사건의 시점에 처리한다.
2. 짧은 발사/충돌 소리와 접촉 지점의 빛도 그 시점에 반응한다.
3. 음정 있는 짧은 잔향·확산 파형·격파 후 빛의 여운은 해당 전투 사건에 맞춰 시작하고 끝난다. 음악의 박자나 분석값을 기다리지 않는다.
4. 박자를 기다리기 위해 총알을 늦게 발사하거나 적의 사망·피해 판정을 미루지 않는다. 음악에 맞춘 공격 주기·리듬 판정은 별도 게임 규칙 변경이며 현재 확정 범위가 아니다.

현재 확정 방향은 **전투 사건에 즉각 반응하는 사운드와 화면 효과**다. 효과의 리듬은 발사·명중·격파·적 공격 자체에서 만들며, BGM의 박자와 직접 맞추는 시스템은 구현하지 않는다.

여기서 말하는 루미네스 참조는 반응의 조합과 감각이다. 사용할 효과음·선율·도형은 SkyWind에 맞게 제작하거나 적합한 기존 자산을 선택하는 제안이며 루미네스의 원본 게임 자산 추출을 작업으로 추가하지 않는다.

노랑은 사용자가 든 강화색의 예시다. 최종 팔레트는 낮/밤·적탄·보급·약점과 함께 비교하고, 색만으로 진영을 구분하지 않는다. 텐션과 격파 체인이 동시에 높아져도 보상음의 음량·피치·레이어를 무한히 쌓지 않는다. 플레이어 피격·저체력 경고의 식별성을 우선한다.

## 4. 음악 직접 연결 제외 — R14 확정

사용자는 음악 직접 연계를 제외하고 전투 사건의 사운드·화면 효과만으로 원하는 연출을 만들기로 했다. 이전 초안의 BGM 박자 격자·예약 음표·조성 분석·음악 시계 통합 제안은 이번 구현에서 제거한다.

- 발사·명중·격파·적 발사를 실제 사건의 시점에 반응시킨다.
- 연속 격파의 음색/음정 변형은 효과음 안에서 정한 작은 계열을 사용할 수 있다. 현재 재생 곡의 음계를 분석해 선택하지 않는다.
- 배경의 장식 반응이 필요하면 실제 충전·발사·격파·일반전/보스전 상태를 따른다. BGM 음량·비트를 읽는 기능을 몰래 추가하지 않는다.
- BGM이 없거나 음소거여도 전투 규칙과 필수 시각 반응은 동일하다.
- 전자음의 음악적인 감각과 BGM에 대한 기술적 동기화는 구분한다. 루미네스 참조는 유지하되 리듬 게임 규칙으로 변경하지 않는다.

전투 난수·점수·충돌은 게임이 소유한다. 음악 분석·음표 선택·장식 파티클 난수가 전투 결과를 바꾸지 않는다. 범용 오디오 엔진이나 큰 외부 의존성은 현 단계에서 제안하지 않는다.

## 6. 가독성·믹스·성능을 함께 다듬는 기준

- 플레이어 탄과 적탄은 색뿐 아니라 형태·진행 방향·핵 표현으로도 구분한다. 텐션의 색 변화가 진영 구분을 뒤집지 않게 한다.
- 적탄은 위험 핵과 짧은 방향 표시를 유지하고 외곽 후광·꼬리·발사구 반응으로 화려함을 만든다. 무장 전 지뢰가 실제 위험 탄처럼 보이지 않게 한다.
- 폭발과 격파 장식은 피해를 주는 탄으로 오인되지 않는 형태·짧은 수명·그리기 순서를 사용한다. 화면 전체를 흰색으로 오래 덮는 연출은 전투 중 기본안으로 두지 않는다.
- 밝은 낮에는 선명한 색과 접촉 대비, 밤에는 외곽 발광과 잔향의 차이로 표현한다. 항상 밤으로 바꾸거나 낮을 어둡게 만들어 해결하지 않는다.
- 많은 명중을 음량 증가로만 표현하지 않는다. 같은 적에 다수의 탄이 맞을 때 즉시 피드백은 남기되 음악적 악센트는 묶고, 소리의 역할·음역·수명을 정리한다.
- 음정 있는 효과에 기존의 무작위 피치 흔들림을 그대로 적용하면 의도한 음계에서 벗어날 수 있다. 해당 큐의 변형을 검토하고, 타격음과 음악적 음표의 변주 규칙을 구분한다.
- 현재 파티클 배열 상한 850과 샘플 보이스 상한 20은 구현 사실이며 새 목표치나 안전 성능 보증이 아니다. 상한을 먼저 올리기보다 입자 형태·시간 곡선·레이어·동시 소리를 설계하고 측정한다.
- 적탄 밀집도 계산과 겹친 발광은 고밀도에서 비용이 늘 수 있다. 실제 병목이 확인된 부분만 조정한다.
- 동작 축소 설정에서는 큰 흔들림·반복 맥동·확산을 줄이되 발사·명중·위험의 즉시 표시를 유지한다. 필수 정보를 장식 축소와 함께 지우지 않는다.

## 7. 기존 초안과의 충돌 처리

| 기존 초안 | 새 방향을 반영한 처리 |
|---|---|
| 기존 폭발·파편을 중심으로 소규모 연결만 수행 | 발사·탄·명중·격파의 표현 자체를 루미네스 참조 방향으로 개정하는 설계 범위로 확대 |
| 기존 효과음을 우선 재사용하고 신규 음악/녹음은 제외 | 원본 보존은 유지. 발사·명중 효과음의 새 제작/합성과 음악의 유지·편곡·교체 필요성을 R15에서 검토 |
| 기존 6곡을 상태별로 교체, boss를 danger보다 우선 | 곡 배정은 현재 미승인 추천안. 효과음과 음악을 직접 동기화하는 요구는 제거하고 혼합·상태 전환만 검토 |
| 현재 기체·파일럿·숲·구름의 디자인 보존 | 플레이어·파일럿·배경은 우선 유지. 적·보스는 D29~D31의 메카닉과 Blender 스프라이트로 새로 제작 |
| 밝은 낮·가속·밤·복귀 | 유지. 각 상태에 맞게 같은 사건의 빛과 음색 밀도를 표현 |
| 기존 발사 간격·피격·점수·보급 일정 | 각 승인될 전투 사양을 따름. 텐션의 발사체 피해 상승은 D34의 의도된 변경이며 음악적 장식이 추가 피해나 타이밍 변경을 만들지 않음 |

새 방향은 상세 설계 요청이다. 먼저 확인할 [1차 범위](FIRST_IMPLEMENTATION.md)는 기존 샘플·짧은 합성음·사건별 렌더를 연결하는 제안이며 그 범위의 구현 지시 후 시작한다. 새 메카닉·외부 오디오 평가기·별도 효과음 제작 앱은 1차 선행 조건이 아니다. 최종 음색·아트 제작의 승인 상태와 분리한다.

## 8. 검토할 선택과 확인 방법

- **R14 확정:** 음악 직접 연계를 제외하고 사건 중심의 시청각 반응을 사용한다.
- **R15:** 필요한 효과음 계열과 기존 BGM의 유지/일부 변경 여부를 혼합 청음 기준으로 정한다. BPM 분석·동기화 준비는 제외한다.
- **R16:** 구체적인 빛의 형태·색·여운과 참조 장면을 받아 목표를 좁힌다.
- **R17:** D32에 따라 [제작 도구](SFX_WORKBENCH.md)의 자율 오디오 평가 모델·연결·검증·자동 채택 범위를 검토한다. Gemini·Qwen의 오디오 입력 경로는 조사했으며 이 게임의 품질 개선은 미실증이다. 사용자의 최초 후보 선택을 필수 조건으로 채택하지 않는다.
- **R20:** 텐션의 게이지·강화색·시작/갱신/만료 큐와 발사·적 명중 변형을 실제 피해 상태에 맞춘다. 피해 배율·지속 세부는 L09에서 관리한다.

사용자의 다른 아이디어를 계속 받아 문서에 반영한다. 구현에 의존성이 생기기 전까지 미결 상태를 명시하며 모든 질문의 답변을 한 번에 요구하지 않는다.

합격 방법은 [검증 기준](QUALITY.md)의 V33~V41과 텐션의 V50~V52·첫 경험 V56에 연결한다. 같은 전투 장면에서 효과만 보이는 비교, 소리를 함께 듣는 비교, 실제 회피 플레이를 구분한다. 관전의 즐거움은 자동 점수로 확정하지 않고 사용자 시각·청음 검토로 확인한다.
