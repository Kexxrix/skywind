# SkyWind 완성도 개선 — 결정 기록

문서판: **2026-09-09 KST / D49 전체 작업 Git 게시·보고서 첨부 승인 반영**.

이 문서는 사용자가 확정한 결정, 남은 질문, 지침 충돌의 처리 근거를 기록한다. 제안과 미결 항목은 구현 승인이 아니다. 최신 사용자 답변을 먼저 반영한 뒤 관련 설계 문서를 같은 의미로 갱신한다.

## 확정된 결정

**최신 지시 D49:** 지금까지 작업한 코드·테스트·기존 검증 자료·인계 문서를 Git에 올리고 작업 내용을 문서로 작성해 함께 첨부한다. I01~I07과 R2~R6를 기존 `Kexxrix/skywind`의 `main`에 커밋·푸시하며 [작업 보고서](../WORK_REPORT_20260909.md)를 포함한다. 원격 차이와 실제 게시 결과를 확인하고 다른 환경 안내를 갱신한다. 이전 D42~D48의 Git 게시 제외는 당시 범위이며 이번 요청은 그 게시를 별도로 승인한다. Sites 공개 배포는 포함하지 않는다.

**최신 지시 D48:** 중앙 회복은 흡수되지만 상하 파워업 계열이 흡수되지 않는 원인을 확인하고 수정한다. 빠르게 들어오되 아이템이 갑자기 사라지는 대신 흡수 이동이 보여야 한다. 원인인 접근 예고 중 흡수 금지를 해제하고, 최소 이동 표시·아이콘 유지·빛 꼬리를 보완한다. 이전 도착 전 획득 금지와 R5의0.10초/거리 기반 조기 종료보다 이 요청이 우선한다. 실제 수치와 예약 보급 검증은 [현재 인계의 R6](../../HANDOFF.md)를 따른다. 로컬 수정이며 Git 게시·공개 배포는 포함하지 않는다.

**최신 지시 D47:** 흡수 범위는 현재의2배 이상이어야 하며 특히 후방 판정을 넓힌다. 빨려 들어오는 동작도 더 신속하고 확실하게 바꾼다. 기본 범위 확대·후방 추가 범위·초기 반응과 시간 단축을 로컬에서 적용한다. 구체 조정값과 검증은 [현재 인계의 R5](../../HANDOFF.md)에서 관리한다. 무기/보급 효과나 플레이어 피해 판정 변경, Git 게시·배포 승인은 포함하지 않는다.

**최신 지시 D46:** 보스가 등장할 때 하단으로 순간 이동하는 오류를 조사하고 수정한다. 실제 원인은 진입 시간이 전투 이동 시계에 섞이는 것이었으며, 고도/카메라와 서로 다른 프레임 조건에서도 전환이 이어지도록 검증한다. 보스 전투 성능을 보상적으로 변경하지 않는다.

**최신 지시 D45:** 아이템 획득 범위를 기체 이미지 폭의 약2배로 넓히고 가까이 가면 기체에 흡수되게 한다. 텐션 상승에 명확한 사운드를 추가하고 전체 사운드를 보완한다. 이전 자동 흡수 보류 및 획득 반경 보존은 이번 요청 범위에서 대체한다. 기존 음원/원본을 유지하면서 연사·명중·폭발·흡수/획득·텐션 사건의 믹스와 우선순위를 조정한다. 실제 수치·기술/브라우저 검증과 청음 한계는 [현재 인계의 R4](../../HANDOFF.md)에서 관리한다. 로컬 구현이며 게시·배포 승인은 아니다.

**최신 지시 D44:** 승인된 무기·시간 연장 HUD는 유지한다. 실제 보급 아이템이 화면 중간에 갑자기 생기는 동작을 오른쪽에서 접근하는 흐름으로 고치고, 최고·최저 고도에서 찾아 획득할 수 있게 한다. 기존 예고 기간에 접근 경로를 연결하고 구름 가림·카메라 좌표·기체 이동 구간과의 불일치를 수정한다. 보급 일정·획득 창·효과·무기 규칙은 유지하며, 실제 조정값과 검증은 [현재 인계의 R3](../../HANDOFF.md)에서 관리한다. 로컬 수정이며 게시·배포 승인은 아니다.

**최신 지시 D43:** 가속을 더 빠르게 표현하고 집중선을 추가한다. 상하 보급의 어두운 그림자와 적탄의 어두운 글로우를 밝은 발광으로 교체하며, 가독성보다 아름다움을 우선한다. 텐션업의 발동·유지 효과를 강화한다. 이 요청은 이전 적탄 C안의 어두운 대비 받침/가독성 우선과 R1 배경 속도 시험값보다 우선한다. 전투 탄속·피격·무기/보급 규칙·음악은 유지한다. 로컬 적용이며 Git 게시·공개 배포 승인을 포함하지 않는다.

**1차 구현 지시 D42:** 사용자가 “구현 안내에 따라 구현 진행. 질문이 필요한 부분은 물어보지 않고 우선판단으로 구현”을 지시했다. FIRST_IMPLEMENTATION I01~I07과 해당 시험값·기존 자산 재사용·첫 두 사이클 범위를 로컬에서 구현·검증한다. 이 범위의 선택은 권장안을 우선 적용하고 실제 조정 이유를 결과에 기록한다. 아래 D04·D07·D39의 구현 미시작/매번 질문 표현은 그 당시 기록이며 이번 범위에는 D42가 우선한다. 전체 메카닉·오디오 제작 도구·극한 난도·Git 게시·Sites 배포는 자동 포함하지 않는다.

**현재 반영:** I01~I07과 후속 R2~R6를 적용했다. 최신 검증·관측·미검증 범위는 [작업 보고서](../WORK_REPORT_20260909.md), R1 당시 자료는 [1차 구현 결과](../first-implementation/README.md)를 따른다. 시험값 채택과 코드 구현 사실을 전체 제작 승인이나 사용자 체감·청음 승인으로 확대하지 않는다.
