# SkyWind 탄막·근접 회피·텐션업 설계

문서판: **검토 초안 1 / 2026-09-08 KST / 구현 미승인**.

작은 피격점과 화려한 탄막 사이를 통과하는 쾌감이 기본 플레이의 중심이다. 첫 사이클에서 ‘생각보다 잘 피한다’는 경험과 우연한 텐션업을 주고, 두 번째부터 조준탄과 패턴의 조합을 본격적으로 어렵게 만든다. 한 사이클은 일반전 45초 + 목표 보스전 약 15초다. 약 5분은 목표 템포에서 극한 난도에 들어가는 예상이며 강제 종료 시각이 아니다.

**확정:** 작은 플레이어 피격점 유지, 적탄의 피해 영역보다 큰 외곽 발광, 근접 회피로 공격력 상승, 우선 지속시간 2초, 연속 회피로 유지되는 감각, 강화된 탄색·발사음·적 명중음, 조준탄 3종 속도 준비, 패턴 4종 고안, 첫 사이클 유도·이후 난도 상승.

**검토 제안:** 근접 범위·피해 배율·재발동 조건·드론 적용, 각 탄막의 탄수·속도·간격·통로 폭·조합이다. 수치 추천을 사용자 확정 답변으로 취급하지 않는다. 이 문서의 탄막 수치와 [레벨 설계](LEVEL_DESIGN.md)의 진행·무기·전체 예산을 함께 검토한다. 먼저 구현할 [1차 확인본](FIRST_IMPLEMENTATION.md)은 첫/두 번째 패턴 값과 텐션을 선택한 범위이며, 해당 범위의 구현 지시 전에는 코드를 만들지 않는다.

## 2. 피격점·적탄 외곽·근접 판정 — L09

### 현재 코드와 유지할 기준

- src/game.js의 `PLAYER_HIT_RADIUS = 1.85`를 유지한다. 핵 반경과 실제 피해 판정이 공유되며 날개·기체 외곽·광번짐은 제외된다.
- 현재 일반 적탄의 충돌 반경은 기본 5.5, 보스탄은 7, 지뢰는 별도 12다. src/renderer.js에는 이 반경보다 큰 후광과 방향 잔상이 이미 있다. 새 탄막의 원형 탄은 우선 해당 반경을 재사용하는 안으로 비교하며 일괄 축소를 전제하지 않는다.
- 기존 충돌은 상대 이동 구간을 검사하고 수학적 접선은 피해에서 제외한다. `graze`라는 주석은 있지만 텐션업 상태·보상 기능은 아직 없다.
- 사용자가 현재 ‘일부러 맞기도 어렵다’고 평가한 것은 플레이 체감이다. 작은 반경 확인만으로 실제 피격률이나 모든 기기의 난도를 측정했다고 쓰지 않는다.

### 세 영역을 구분

| 영역 | 의미 | 추천 처리 |
|---|---|---|
| 실제 충돌 | 플레이어 핵과 적탄 피해 영역의 겹침 | HP 피해. 기존 엄격한 겹침 판정 유지 |
| 근접 회피 | 충돌하지 않았지만 핵 가까이를 지나간 적탄 | 텐션업 발동/갱신 후보 |
| 외곽 발광·꼬리 | 탄막의 화려한 첫인상과 방향 표현 | 피해나 텐션업 범위를 결정하지 않음 |

원형 탄의 상대 이동 중 최소 중심 거리를 `d`, 플레이어 반경을 `rp=1.85`, 적탄 반경을 `rb`, 근접 여유를 `G`라고 한다. 충돌 경계는 `R=rp+rb`다. 기존 수치 오차 처리를 유지하면서 `d < R`이면 피해, 피해가 없고 `R ≤ d ≤ R+G`이면 근접 회피 후보로 삼는 안이다.

초기 `G=12`를 제안한다. 일반 탄은 `R=1.85+5.5=7.35`, 근접 영역의 바깥 중심 거리는 `7.35+12=19.35`다. 이 12는 확정값이 아니며 첫 사이클에서 자연스럽게 발생하는 빈도와 정밀 회피의 의미를 실제 플레이로 조정한다. 기체 이미지 가장자리만 스치는 것은 발동 기준이 아니다.

외곽 발광은 피해 영역보다 크게 그리되 작은 위험 핵·방향 표시는 유지한다. 보이는 중심조차 통과해야만 살 수 있는 식으로 판정을 숨기거나, 플레이어가 접근하면 탄의 판정이 자동으로 줄어드는 보정은 넣지 않는다. 난도 단계가 올라도 동일한 탄의 충돌/근접 반경은 그대로다.

### 텐션업 상태·갱신 제안

| 사건 | 추천 동작 |
|---|---|
| 첫 유효 근접 회피 | 텐션업 시작, 남은 시간 2초 |
| 활성 중 다른 유효 근접 회피 | 남은 시간을 다시 2초로 갱신. +2초씩 비축하거나 피해 배율을 중첩하지 않음 |
| 같은 탄과 계속 가까이 있거나 재접근 | 탄 ID당 한 번만 인정. 느린 탄 하나로 무한 유지하지 않음 |
| 유효한 새 탄을 연속으로 스침 | 마지막 근접 회피부터 2초 동안 유지. 여러 탄이 같은 순간 스쳐도 시작음·HUD 반응은 묶음 처리 |
| 실제 피격 | 텐션업 해제 제안. 같은 업데이트 구간에 피격이 있으면 근접 보상을 남기지 않음 |
| 피격 무적 중 | 새 근접 보상 없음. 의도적으로 맞아 무적 시간에 보상을 얻는 경로 방지 |
| 무장 전 지뢰·제거된 탄·장식·적 몸통 | 발동 대상에서 제외. 우선 실제 피해 가능한 적탄만 대상 |
| 탄막 자동 정리·보스 격파 | 정리된 탄을 근접 회피로 보상하지 않음. 이미 얻은 남은 시간은 일반 게임 시간으로 만료 |
| 일시정지·창 이탈 | 남은 시간과 근접 판정 정지. 복귀 후 밀린 보상 없음 |
| 게임오버·재도전·타이틀 | 상태·탄별 처리 기록 초기화 |

위 세부 규칙은 R20에서 검토한다. 사용자가 확정한 것은 2초 지속과 연속 회피로 이어지는 감각이며, 탄별 1회·피격 해제까지 확정했다고 쓰지 않는다.

고속 탄은 프레임 끝점만으로 검사하지 않는다. 기존 상대 이동 검사와 무장 시점을 재사용하여 관통한 근접 영역도 검출한다. 먼저 피해 여부를 확정하고 피해를 준 탄을 근접 보상으로 중복 처리하지 않는다. 탄 배열 순서나 화면 FPS가 결과를 바꾸지 않게 한다.

### 피해량과 다른 강화의 관계

초기 추천은 **기본·특수 주무기와 드론의 발사체 피해 1.5배**, 발사 간격·탄수·관통 횟수·이동 속도·피격점은 동일하게 두는 것이다. 무기별 차이를 보존하면서 강화가 느껴지는 출발점이며 피해 배율과 드론 포함은 R20의 미결 제안이다.

- 텐션업은 기본 레벨이나 특수 무기 시간을 바꾸지 않는 별도 상태다. 기존 `powered` 값을 통째로 재사용해 특수/드론/파일럿 상태가 함께 바뀌게 하지 않는다.
- 탄을 발사할 때 텐션 여부·피해 배율·탄색/발사음·명중음 변형을 고정하는 안을 제안한다. 이미 날아가는 탄을 소급 강화하거나 텐션 종료 순간 약화하지 않는다.
- 같은 발사체의 피해는 `무기/기본 레벨 피해 × 발사 시 텐션 배율 × 명중 부위 배율` 한 번으로 계산한다. 장갑·약점은 R18에서 확정한다.
- 텐션 1.5배와 약점 1.5배를 함께 채택한다면 합계는 `1.5×1.5=2.25배`다. 둘 다 아직 검토 수치다. 텐션을 HUD 효과로만 적용하거나 약점과 중복 명중 처리하지 않는다.
- 점수 배율·회복·탄 소거·무적·입력 속도 상승을 텐션 보상에 자동 추가하지 않는다.

첫 보스 HP 420과 기본 Lv.1의 단순 전탄 명중 피해율 약 21.05/초를 그대로 사용하면, 텐션 없이 `420÷21.05≈19.95초`, 1.5배를 계속 유지하면 `420÷(21.05×1.5)≈13.30초`다. 실제로는 진입·개방·명중률·유지 비중이 있으므로 처치 시간 검증을 대신하지 않는다. 기존 목표 15초를 맞춘다는 이유로 실시간 플레이에 따라 HP를 몰래 조절하지 않는다.

## 3. 일반 조준탄과 패턴 공통 규칙 — L10

일반 잡몹의 기본 사격은 **발사 순간 플레이어의 현재 핵 위치로 향하는 직선탄**으로 개정한다. 현재 코드는 예고 시작에 방향을 고정하므로 이 부분이 변경 대상이다. 회전 패턴의 모든 탄을 플레이어 추적탄으로 만들지는 않는다.

초기 조준탄 속도 3종은 `느림 160 / 보통 240 / 빠름 340`을 제안한다. 단위는 기존 1280×720 게임 좌표/초다. 첫 사이클은 느림 위주, 두 번째는 보통과 구분되는 빠른 탄을 섞고 이후 3종의 도착 차이를 활용한다. 모든 속도를 난도 배율로 같은 값까지 밀어 올려 3종의 차이를 없애지 않는다.

- 예고 중 포구가 플레이어 방향을 따라갈 수 있으나 탄이 나온 뒤에는 방향·속도를 고정한다. 미래 위치를 예측하거나 뒤늦게 휘어 맞히지 않는다.
- 예고는 해당 무장의 충전과 공격 준비를 보여 준다. 움직이는 조준선을 쓰면 발사까지 따라가는 것을 화면에서도 보여 주며, 이미 고정된 안전선처럼 표시하지 않는다.
- 기본은 1발이다. 연속 사격을 쓰면 각 발의 실제 발사 순간을 기준으로 새로 조준하며, 간격과 발수는 명시한다. 첫 사이클에서는 빠른 재조준 연사를 쓰지 않는다.
- 속도 구분은 색 하나에만 의존하지 않고 탄두의 길이·방향 잔상·충전음의 차이로 보조한다. 적탄의 위험 색 계열은 유지한다.
- 실제 포구에서 플레이어의 현재 충돌 경계까지의 도달 시간이 너무 짧으면 그 공격을 늦추거나 보류한다. 처음에는 최소 0.9초, 두 번째에는 0.7초, 극한에서는 0.5초를 검토한다. 충전 예고와 탄이 나온 뒤의 회피 시간을 구분한다.
- 예를 들어 빠름 340에서 0.5초의 비행 여유는 `340×0.5=170`의 거리다. 실제 중심 거리에는 플레이어·탄 반경을 더해 확인한다. 화면 X 차이 120만으로 이 조건을 통과했다고 판단하지 않는다.
- 탄막을 피하려고 멈춘 플레이어에게 조준탄이 이동을 요구하고, 이동 뒤 새 위치에서는 다음 빈 공간을 읽게 한다. 세 속도를 예고 없이 한 점에 동시에 겹치게 발사하는 것을 기본 공격으로 삼지 않는다.

## 4. 패턴 4종 — 앞 절 L10의 상세안

아래 수치는 **첫 사이클 → 두 번째 사이클 → 극한 단계** 비교용 출발점이다. 3~5사이클의 보간·조합은 레벨 예산을 따르며 최종 값은 R21에서 결정한다. 모든 탄은 보이는 기체 포구/배치된 포격 모듈에서 나온다. 빈 공간에 피해 탄을 갑자기 생성해 벽 모양만 맞추지 않는다.

### B01. 회전하는 겹고리

- **그림:** 360도 고리를 조금씩 돌려 연속으로 발사하여 겹친 꽃잎과 나선 같은 궤적을 만든다. 원형 탄 한 발은 직선으로 움직이고 발사 위상이 바뀌어 큰 회전 그림이 생긴다.
- **규칙:** 한 고리에서 `θ(k)=2πk/N+φ`, 다음 고리는 `φ`를 일정 각도만 회전한다. 한 묶음 중 회전 방향은 고정한다. 예고한 빈 각도를 제외할 수 있으며 실제 회피 공간으로 검증한다.
- **출발값:** 고리당 `18 / 24 / 40발`, `3 / 3 / 5고리`, 고리 간격 `0.65 / 0.50 / 0.35초`, 위상 변화 `8 / 10 / 12도`, 속도 `120 / 145 / 180`.
- **선택:** 같은 틈을 따라 조금 움직이면 안전하고 가장자리를 타면 텐션을 이어갈 수 있다. 멀리 크게 도망치면 다음 고리와 조준탄의 도착 방향을 다시 읽어야 한다.
- **조준탄 조합:** 첫 사이클은 고리가 읽힌 뒤 느린 단발 1개. 두 번째부터 고리 사이에 보통 조준탄을 넣는다. 극한에서도 새 고리의 좁은 통로를 빠른 탄이 같은 시각에 완전히 막는 배치는 제외한다.
- **메카닉:** 사각 회전 노드/다중 포트 중간급과 에너지 코어 보스. 여러 포트의 총 탄수는 고리당 N 안에 포함한다.

### B02. 지그재그 탄 줄

- **그림:** 발사 각도를 위아래로 왕복해 삼각형·마름모처럼 이어지는 탄 줄을 만든다. 두 발사구를 시간차로 사용하면 서로 엇갈린 직조 형태가 된다.
- **규칙:** 중심 방향을 `π+A·sin(φ)`로 변화시키며 짧은 3~5발 묶음을 순차 발사한다. 개별 탄은 발사 후 직선으로 간다. 탄 자체가 갑자기 방향을 꺾는 방식은 이번 기본안에 넣지 않는다.
- **출발값:** 포구 수 `1 / 2 / 2`, 포구당 묶음 수 `8 / 10 / 14`, 묶음당 `3 / 3 / 5발`, 간격 `0.22 / 0.20 / 0.16초`, 중심 왕복 폭 `±18 / ±22 / ±26도`, 속도 `125 / 150 / 185`. 두 포구의 시작 시차는 `0.4초`를 검토한다.
- **선택:** 탄 줄과 같은 방향으로 따라가다가 방향이 바뀌기 전에 옆 줄의 빈 공간으로 이동한다. 전 화면을 왕복하기보다 근처 빈 칸을 고르는 조작을 만든다.
- **조준탄 조합:** 첫 사이클은 패턴 단독으로 읽게 한다. 두 번째부터 탄 줄의 진행 중간에 단발을 넣어 한 통로에 계속 머무르지 못하게 한다. 극한에서는 두 포구의 시차를 유지하며 중·고속 조준탄의 도착을 분리한다.
- **메카닉:** 상하 가동 포구가 있는 중간급·연동 포격기. 두 독립 기체면 공격원 2개를 함께 예약한다.

### B03. 느린 규칙성 산개

- **그림:** 덩어리의 간격과 밀도가 조금씩 달라 성운처럼 보이지만, 각 묶음 안에서는 같은 방향·속도를 공유하는 느린 탄막이다.
- **규칙:** 전방 부채꼴의 기준 각도를 여러 구역으로 나누고 시드로 작은 편차를 한 번 정한다. 예를 들어 구역 중심 각도에 최대 ±6도의 편차와 최대 ±5% 속도 차이를 주되, 묶음 내부의 정렬과 통과 공간을 유지한다. 프레임마다 무작위 방향을 다시 뽑지 않는다.
- **출발값:** 한 줄의 총 탄수 `18 / 24 / 36발`, `3 / 4 / 5줄`, 줄 간격 `0.85 / 0.65 / 0.45초`, 기준 속도 `110 / 130 / 160`. 난수 편차까지 L02 최대 탄속·탄수에 포함한다.
- **선택:** 멀리 흩어진 탄을 모두 따라보지 않고 자신의 다음 이동 공간을 읽는다. 느린 탄 옆에서 텐션을 얻을 수 있지만 같은 탄 하나에 붙어 유지할 수는 없다.
- **조준탄 조합:** 첫 사이클은 느린 단발을 산개 사이에 충분히 떨어뜨린다. 두 번째부터 보통/빠른 단발이 느린 탄막을 가로질러 들어온다. 빠른 조준탄의 경로에 이미 피할 수 없는 산개 덩어리를 배치하지 않는다.
- **메카닉:** 복수의 전방 포트가 있는 포격정·드론 모함. 고유한 실루엣은 메카닉 문서에서 결정한다.

### B04. 이동하는 창과 교차 사격

- **그림:** 상하 포구에서 나오는 탄 줄이 전방에서 커튼처럼 정렬되며 빈 창을 만든다. 다음 줄의 창은 위나 아래로 조금 이동한다.
- **규칙:** 플레이어 영역 앞의 기준 단면에 도착할 Y 지점들을 먼저 정하고, 실제 포구에서 그 지점으로 직선 발사한다. 빈 창의 중심은 한 묶음 시작 때 정한 순서로 이동한다. 탄은 단면에서 멈추거나 재조준하지 않는다.
- **출발값:** 두 포구 합계 한 줄 `20 / 28 / 40발`, `2 / 3 / 4줄`, 줄 간격 `0.95 / 0.75 / 0.55초`, 속도 `140 / 165 / 200`. 창의 실제 여유 폭은 5절과 L02를 따른다.
- **선택:** 지금 창의 가장자리에서 텐션을 얻을지, 다음 창으로 먼저 이동할지 고른다. 늦은 출발·큰 왕복 때문에 스스로 갇히는 결과는 남긴다.
- **조준탄 조합:** 첫 사이클은 첫 창 통과를 확인할 시간 뒤 느린 단발 1개. 두 번째부터 창 사이의 이동을 요구하는 중속탄을 섞는다. 극한에서는 상하 포구의 시차와 3속도 조준탄을 결합하되 단면의 창뿐 아니라 전체 이동 경로가 열려 있어야 한다.
- **메카닉:** 상하 포격 모듈을 전개하는 모함·다포탑 보스. 포구의 위치·개방 애니메이션과 탄 출발 좌표를 연결한다.

## 5. 빈 공간의 의미와 패턴 겹침

‘통로가 있다’는 것은 그림에 틈이 있다는 뜻만이 아니다. 탄의 충돌 영역에 플레이어 반경을 더해 확장한 뒤, **플레이어 핵 중심이 실제로 이동 가능한 공간**을 본다.

이 문서의 `W`는 그 확장 이후 남는 핵 중심의 통로 폭이다. 동일 반경 `rb`인 두 탄의 중심 간격이 `S`이면 직선 단면의 여유는 `W=S-2×(rb+rp)`다. 일반 탄 rb=5.5에서 W=80이면 S는 `80+2×(5.5+1.85)=94.7`, W=10이면 S는 `24.7`이다. 발광이 겹쳐도 충돌 통로는 열릴 수 있다. 이 식은 동시 이동과 교차 탄막의 안전을 보증하지 않는다.

- 통과 가능한 위치·시간을 묶어 검토한다. 서로 다른 시각에 따로 존재하는 두 틈을 하나의 회피 경로로 계산하지 않는다.
- 조준탄은 멈춘 플레이어를 움직이게 하는 공격이므로 모든 현재 위치를 항상 안전하게 보정하지 않는다. 합리적인 진입 위치에서 정상 입력으로 이어지는 생존 경로와 이동 판단 시간을 확보하는 것이 목표다.
- 첫 사이클에는 패턴 하나와 느린 조준탄 하나의 관계를 먼저 보여 준다. 두 번째부터 패턴+조준탄을 본격적으로 겹친다. 극한의 추가 패턴은 기존 패턴의 끝부분과 다음 패턴의 시작이 연결되는 제한된 중첩으로 제안한다.
- 활성 탄수는 결과 제한이다. 탄이 이미 꽉 찬 뒤 아무 탄이나 잘라내는 대신, 다음 발사 묶음의 예산을 먼저 예약하고 통로와 도형이 유지되는 축소형을 선택한다. 준비하지 못하면 발사를 보류한다.
- 원작 Extreme의 격파 반격탄은 조사 근거로만 남긴다. 근접 격파 순간 예고 없이 탄이 터지는 시스템은 현재 추가 승인 대상이 아니다.
- 고도별 보급의 도착 지점을 탄막으로 계속 봉쇄하지 않는다. 보급 선택에는 위험이 있지만 상하 양쪽 획득 가능성은 L07의 정상 입력 검사로 별도 확인한다.

## 6. 사이클별 경험과 배치

| 사이클 | 체감 목표 | 추천 조합 |

| 1 | 화려하지만 넓게 피할 수 있고 우연한 텐션업을 알아차림 | 패턴 4종을 짧게 단독 소개, 느린 조준탄 위주. 고속 재조준·두 패턴 본격 중첩 없음 |

| 3 | 통로 선택과 텐션 유지가 경쟁 | 패턴 간 시간차·탄속 차이를 읽기. 중간급 먼저 격파해 조준 압박을 줄이는 선택 |

첫 사이클 일반전의 제안은 `0~6초` 가벼운 격파/느린 조준탄, `6~14초` B01, `14~22초` B02, `22~31초` B03, `31~39초` B04, `39~42초` 가벼운 정리, `42~45초` 보스 예고다. 보급 시각은 L07·L08을 유지해 함께 검토한다. 패턴 4종을 처음부터 한꺼번에 겹치지 않는다.

첫 보스는 B01·B04를 더 큰 기체의 개방/발사에 연결하는 안이다. 15초 목표 안에 모든 패턴과 기믹을 반드시 끝내도록 강제하지 않는다. 두 번째 보스부터 조준 압박과 익힌 형태의 재조합 비중을 높인다. 최종 배정은 R04·R18·R21에서 확정한다.

6사이클 이후에도 반드시 죽게 하는 숨은 명중탄·시간 제한·회피 불가능한 전면 봉쇄·피격점 확대를 넣지 않는다. 사용자의 ‘죽을 수밖에 없어 보이나 매우 정교하면 유지’는 고난도 생존 목표이며 절대적인 강제 사망 규칙이 아니다.

## 7. 화면·소리·코드 연결

- 텐션 시작은 짧은 핵 주변 반응과 작은 `TENSION`/2초 게이지로 알리는 안을 제안한다. 첫 발동만으로 의미를 알아차릴 수 있어야 하지만 큰 문구가 피격점을 가리지 않는다.
- 탄색은 무기 고유 형태를 유지하며 채도를 높이거나 황금/노랑 계열을 얹는 안을 검토한다. 적탄·보급·약점과 혼동하지 않게 실제 낮/밤에서 비교한다.
- 발사음과 적 명중음은 더 선명한 시작·에너지층·짧은 공명으로 고조한다. 연속 스침마다 음량·피치가 무한히 올라가지 않는다. 기존 체인 소리와 보이스 예산을 공유한다.
- 탄의 발사 시 텐션 정보를 명중 이벤트까지 전달하여 강화 탄의 실제 피해와 명중음이 일치하게 한다. 발사 당시 소리만 바뀌고 명중은 무관한 큐가 나오는 상태를 피한다.
- 텐션은 실제 피해 규칙이므로 src/game.js의 상태다. 렌더링·오디오·HUD는 사건을 읽는다. 음악과 직접 연계하지 않는다.
- 파일럿의 기존 피격 > 저체력 > 강화 > 정상 우선순위는 유지한다. 텐션을 별도 파일럿 초상 상태로 자동 추가하지 않는다.
- 상세 색·음색과 제작은 [빛·소리 연출](AUDIO_VISUAL.md), [효과음 제작](SFX_WORKBENCH.md)을 따른다. ‘설계할 기반이 있다’는 것과 새 음원·유동적 믹스가 이미 완성됐다는 것은 구분한다.
