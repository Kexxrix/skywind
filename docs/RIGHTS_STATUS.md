# 사운드 공개 사용 확인 기록

기준일: **2026-09-07 KST**.

사용자는 공개 저장소 `Kexxrix/skywind`의 전체 백업 방식에 관한 질문에 다음과 같이 답했다.

> 사운드 공개 사용 권한이 확인됐으니 공개 저장소에 전체 백업

이 사용자 확인을 근거로 `assets/audio/sfx-patch1/`의 제공 원본 67개와 편집 WAV 30개를 공개 GitHub 백업에 포함한다. 현재 `provenance.json`의 `publicationApproved`와 각 편집 항목의 승인값은 true이며, `rightsEvidence`는 이 확인의 날짜·출처·범위를 기록한다. 원본/편집본 바이트와 기존 SHA-256은 변경하지 않는다.

이는 사용자가 권한을 확인했다는 기록이다. Codex가 별도의 라이선스 문서나 권리자를 독립 조사한 결과는 아니며, 모든 자산에 CC0/MIT 등의 새 라이선스를 부여한 것도 아니다. 기존 CC0 효과음의 원문 라이선스는 기존 자산 폴더에 보존한다. 제공 사운드의 `humanListeningVerified`는 계속 false다.

과거 QA 문서·편집 보고서에 남아 있는 권한 미확인 표기는 작성 당시의 사실이므로 수정하지 않는다. 현재 상태는 이 문서와 현재 provenance를 기준으로 한다. 최초 GitHub 백업 후 별도의 사용자 지시로 기존 Sites 공개 게임에도 같은 사운드를 포함한 버전 3을 배포했다. [배포 기록](PUBLIC_UPDATE_20260907.md)을 참고한다.
