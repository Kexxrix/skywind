# SV-01 R4 플레이어 적용

승인된 R4 외형·재질·조명을 고정한 본체 리소스입니다. 현재 프로젝트에 연결되어 있습니다.

- 실제 경로: `E:/codexwork/skywind/assets/art/player/sv01/` (프로젝트 상대 경로 `assets/art/player/sv01/`).
- 게임용 PNG **21장**, 각 `256×256 / 8-bit RGBA / 완전 투명 배경`. 별도 확인 이미지 `preview_sheet.png`, `alpha_check.png` 각 1장. 매니페스트 1개와 이 문서 1개를 포함해 폴더 총 25파일입니다.
- 이름: `sv01_bank_{00..20}_{desc|neutral|asc}_{각도}.png`. 소수점은 `p`로 표기합니다. 예: `sv01_bank_01_desc_66p6.png`.
- 순서: **00–09 하강 74.0→7.4° / 10 중립 0° / 11–20 상승 7.4→74.0°**, 간격 7.4°. 90° 포즈는 없습니다.
- 피벗: 모든 PNG의 **(128,128)**, 정규화 **(0.5,0.5)**. 고정 사이드 카메라·동일 축척이며 프레임별 크롭/중앙 재정렬을 하지 않았습니다. 자세에 따라 투명 영역과 투영 외곽 범위가 달라지는 것은 정상입니다.

## 코드 연결

`src/renderer.js`의 `Renderer.load()`가 `manifest.json`의 `frames` 순서대로 PNG를 읽어 `this.playerFrames`에 저장합니다. `drawPlayer()`의 본체 이미지가 새 배열을 사용합니다.

```js
const bankFrame = Math.round(10 - clamp(p.angle / .48,-1,1) * 10);
c.drawImage(this.playerFrames[bankFrame],-53,-53,106,106);
```

기존 `p.angle`의 이동 보간을 그대로 사용합니다. 양수는 하강, 음수는 상승이며 최대 기울기 ±0.48을 시퀀스의 양 끝에 연결합니다. 게임의 `p.angle`(라디안 신호)과 매니페스트의 기체 뱅크 각도(도)는 별개입니다. 새 보간 상태나 타이머를 추가하지 않았습니다. 기존 `p.angle * 2.4` 화면 회전, 106×106 표시 크기, 플레이어 중심 좌표를 유지합니다.

이전 PNG는 1254×1254였지만 소스 크기를 요구하는 코드가 없고 항상 106×106으로 축소했습니다. 새 리소스는 승인된 256 규격을 사용하며 화면 크기를 바꾸지 않습니다. PNG는 1024 원본을 알파 선곱 Lanczos로 1/4 축소하고 완전 투명 픽셀의 RGB를 0으로 정리했습니다. 검은 배경 제거 방식이 아닙니다.

`tools/build-site.mjs`도 매니페스트와 21 PNG를 포함하도록 연결했습니다. `tests/player-sv01.test.js`는 자산 계약·포즈 방향·기존 표시 변환·게임 상태 보존·드론 분리를 검사합니다.

## 보존 및 범위

- 본체에 쓰던 `assets/art/player.png`의 참조만 교체했습니다. 원본 파일은 보존하며 기존 드론 표시는 계속 그 파일을 사용합니다.
- 본체 PNG에는 노즐 구조만 있고 추진 불꽃·분사광·드론·변형·무기 상태별 파츠가 없습니다. 기존 게임이 별도로 그리는 궤적·광원·무기·드론 효과는 변경하지 않았습니다.
- `src/game.js`의 이동·피격 반경 1.85·발사 위치·무기·난이도는 변경하지 않았습니다.
- 추가 외형 수정이나 R4 재질 탐색은 하지 않았습니다. 승인 원본의 SHA-256은 매니페스트에 기록되어 있습니다.

## 실행·인계

```powershell
npm test
npm run check
npm run build:site
npm start
```

`http://127.0.0.1:5173/`에서 새로고침 후 START → 방향키 상승/하강 → 입력 해제(중립)로 확인합니다. 이미 열린 페이지는 새로고침해야 새 모듈과 PNG를 읽습니다. 공개 사이트 배포·Git 커밋/푸시는 이번 범위에 포함하지 않습니다.

전달 ZIP은 프로젝트 상대 구조의 변경 파일만 담습니다. 기준 버전은 `d0b0910a1bc51604b759d516f29d4ced8acb5651`입니다. 적용할 때 먼저 로컬 변경을 확인하고 같은 위치에 복사합니다. 전체 게임이나 실행에 필요한 기존 자산을 대체하는 압축파일은 아닙니다.
