# 파일럿 제공 원본 및 배치 참고

2026-09-08 GitHub 백업을 위해 사용자가 제공한 `Temp/`의 PNG 9장을 파일명과 바이트를 유지해 복사했다. 원래 폴더는 유지하며, 이후 PC에서는 이 폴더를 사용한다.

- 실제 초상 원본: 기본표정1, 기본표정2, 파워업, 낮은체력, 피격.
- 배치/연출 참고 화면: 기본상태, 낮은체력경고, 낮은체력경고연출, 피격연출.
- 실행 사본은 상위 `assets/art/pilot/`의 영문 이름 PNG 5장이다. 참고 화면은 게임에 표시하지 않는다.
- 복사한 9개 파일 모두 원래 파일과 SHA-256 일치를 확인했다. 픽셀 편집·압축·재생성은 하지 않았다.
- 이 폴더는 GitHub 작업 백업에 포함되며 정적 게임 배포 패키지에는 포함되지 않는다.
