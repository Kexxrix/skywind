# SkyWind 실제 3D 메카닉 패밀리

## 현재 상태

일반 역할 9종과 보스 역할 5종을 실제 Blender 메시로 제작했다. 기존 승인 대표 `beetle`은 픽셀/원본 해시를 유지한 어댑터 복사이며, 나머지는 승인된 대표 장면의 카메라·조명·재질·색 관리 데이터를 그대로 불러와 새 형상을 제작했다.

이 폴더는 아트 제작·정적 검증 결과다. 실제 게임 적용, 공격/약점 충돌 검증, 최종 아트 채택은 별도로 구분한다. 검토 이미지는 과거 낮/밤 이미지 위에 자산을 합성한 컨셉 적합성 자료이며 게임 실행 스크린샷이 아니다.

부모 아트 감독은 전체 실루엣/기구 방향의 게임 통합을 승인했다. 전체 패밀리 독립 검토와 실제 런타임 수용 검증은 아직 대기 상태다.

표시 폭은 `beetle 87`만 로컬 구현 담당자가 지정한 확정값이다. 나머지는 아트 비교용 임시값이며 로컬 구현 담당자의 최종 적응을 기다린다: dragonfly 88, wasp 76, mantis 96, orb 82, claw 108, ray 118, worm 170, needle 112, warden 340, carrier 300, lancer 360, bastion 300, apex 340. 표시 폭만 바꿀 때는 메타데이터만 수정하며 재렌더가 필요하지 않다.

## 재사용 구조와 역할 구분

- 쐐기/분리 팔: `beetle`의 승인된 겹장갑 요격기, `wasp`의 가는 창형 고속기, `mantis`의 분리 갈고리 무장 팔
- 각진 프레임: `dragonfly`의 작은 사각 회전 드론, `orb`의 8분절 방사 프레임과 좌향 3포트
- 장갑 압박 기체: `claw`의 밀집 2포격 어깨, `ray`의 넓은 상하 발사 통로
- 긴 포격 구조: `worm`의 4연결 장갑 모듈과 3포트, `needle`의 긴 레일포와 반동 캐리지
- 보스 `warden`: 중앙 장갑 턱이 분리되어 작은 핵을 노출
- 보스 `carrier`: 상하 격납문이 열려 실제 모델링된 소형 프레임이 보이고 함교 셔터가 열림
- 보스 `lancer`: 긴 중앙 창이 전진하고 양쪽 레일/셔터가 벌어짐
- 보스 `bastion`: 상하 포격 어깨와 4포신이 전개되고 중앙 셔터가 열림
- 보스 `apex`: 6개의 방사 장갑 꽃잎과 중앙 케이지가 분리됨. 핵은 작은 독립 부품이며 동체 전체가 발광하지 않음

## 파일

- `family_generator.py`: 신규 13종의 편집 가능한 메시와 기구를 생성하고 실제 Cycles 렌더·투영 메타데이터를 내보내는 코드
- `representative_generator.py`: 승인된 최초 대표 생성 코드의 변경 없는 사본
- `sources/*.blend`: 역할별 완전한 메시·재질·카메라·조명과 부품 부모 관계. 신규 13종의 기구는 프레임 1(중립)과 21(전개)에 실제 변환 키프레임을 가짐
- `renders/*.png`: 384×384 투명 RGBA. 24장. 전체 디코딩 기본 픽셀 메모리 13.5 MiB
- `*-manifest.json`: 각 역할·상태의 포구, 추진구, 핵과 반경의 실제 카메라 투영값
- `family-manifest.json`: 모든 역할의 수집본과 공통 좌표·충돌 연결 설명
- `validation.json`: 알파 여백, 해시, 앵커 범위와 보스 핵 가시성 검사
- `review/`: 소수의 검토 이미지와 재생성 코드

## 좌표/상태 계약

- 모델 전방 -X, 우현 +Y, 위 +Z. 적의 발사 방향은 화면 왼쪽
- 고정 직교 카메라 `(0,-15,4)`, ortho scale `5.15`. 승인된 대표와 같은 데이터이며 원본 SV-01의 미확보 카메라 수치와 같다고 주장하지 않음
- 이미지 픽셀 원점 왼쪽 위. 피벗 `(192,192)`. 상태별 자동 크롭·재중앙·크기 조절 없음
- 포구·추진구·핵·핵 반경은 모델 Empty를 `world_to_camera_view`로 투영. 가동 포구는 실제 무장 부모와 함께 움직임
- `neutral`은 핵이 작은 상태 표시로 보이더라도 보너스 피해를 주지 않음
- `open`은 물리 전개 끝점. `needle`의 `open`은 핵 개방이 아니라 레일 반동/복귀 포즈이므로 별도 약점 규칙을 승인하지 않음
- 상태의 `coreExposed`는 전개 상태 표지이며 화면에 점이 보이는지와 혼동하지 않음. 실제 가시성은 `coreVisibleFromCamera`와 `coreCameraRayFirstMesh`에 별도 기록
- 보스 5종은 중립 핵을 실제 장갑으로 가리고, 전개 시 카메라에서 핵 메시가 직접 보이는 것을 광선 검사로 확인
- 기본 몸통 판정과 핵 보너스 활성은 게임 전투 상태가 결정. 이 아트 파일은 새 피해 배율, 무적 시간, HP, 판정 규칙을 승인하지 않음
- 발광 불꽃·총알·섬광·추력 잔상은 PNG에 포함하지 않음
- 중립/전개 끝점만 출력. 전체 중간 프레임 조합을 과잉 생산하지 않았으며, 필요할 때 실제 소스 기구에서 중간 상태를 렌더할 수 있음

## 재현

Blender 4.3.2, CPU Cycles 128 samples, 384×384, denoising 비활성화. 이 환경의 Blender는 OpenImageDenoise를 포함하지 않아 설치 없이 해당 기능을 끄고 렌더했다.

기본 명령: `blender --background --python family_generator.py`

일부 역할: `blender --background --python family_generator.py -- --roles warden carrier`

승인 대표 `.blend`의 기본 경로는 이 폴더의 상위 `interceptor-representative/int01-wedge.blend`다. 다른 위치에서는 `--base`로 경로를 지정한다. 원본 .blend를 다른 컴퓨터에서 열어 직접 렌더할 때 출력 폴더를 해당 컴퓨터의 경로로 지정한다.

검토/정적 검증 코드: `python3 review/validate_and_review.py`. 검토 배경은 기존 참조 폴더를 사용한다. 런타임 패키지는 배경 파일을 새로 생성하거나 교체하지 않는다.

## 보존

기존 플레이어/파일럿/배경/게임 원본을 수정하지 않았다. 승인 SV-01 중립 PNG 해시는 `530b68cbad52545909579ad8d922fa933b85aecc8a2fab954c83760451ad0c9f` 그대로다. 실제 3D 생성과 렌더만을 제작 출처로 기록하며, 미실행 게임 검증·사용자 승인·원본 카메라 확보를 주장하지 않는다.
